# Adventistas Valdivia

1. Sube todos los archivos a tu repositorio `adventistas-valdivia` (incluida la carpeta `.github`).
2. Espera unos 10 minutos: en **Releases** estarán los instaladores de Windows y Mac.

Para actualizar: sube el número de `version` en `package.json` y guarda. Las computadoras se actualizan solas.

Mac: para abrir sin avisos hace falta cuenta Apple Developer (de pago).
